Usuarios y publicaciones

La aplicación consulta usuarios y publicaciones de JSONPlaceholder. No requiere instalar dependencias: abre index.html con conexión a internet.

Vista de la funcionalidad

Cómo consultar publicaciones

  1. Abre la sección Usuarios y publicaciones desde el menú o desplazándote hacia abajo.
  2. Espera a que aparezca la lista de usuarios con nombre, correo electrónico y empresa.
  3. Selecciona Ver publicaciones en cualquier usuario.
  4. Consulta los títulos y contenidos en el panel de publicaciones. Al seleccionar otro usuario, los resultados se actualizan.
  5. Si falla la conexión, lee el aviso y usa el botón de reintento cuando se restablezca.

Ver las consultas en DevTools

  1. Abre DevTools con F12 y entra en la pestaña Network. Activa Fetch/XHR y limpia la lista.
  2. Recarga la aplicación. Debe aparecer GET /users con respuesta 200.
  3. Selecciona un usuario. Debe aparecer GET /posts?userId=ID, donde ID coincide con el usuario seleccionado.
  4. Selecciona un usuario distinto y confirma que se envía otra consulta con su ID.

Las solicitudes se hacen con la API Fetch del navegador; no se necesita Axios ni una clave de acceso.

Para explicar y modificar

En script.js, loadUsers() consulta la lista de usuarios y loadPosts(userId) construye la URL con el ID seleccionado. Ambas funciones muestran estados de carga y manejan errores.

Modificación pequeña para la revisión: cambia el texto del botón Ver publicaciones dentro de renderUsers(), por ejemplo a Publicaciones de este usuario, y comprueba que la selección siga funcionando.
